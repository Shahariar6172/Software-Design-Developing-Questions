**Q1.** [5]
 
(a) Define software design.

(b) In the case of software, what is the input of the design process?

(c) Name the two basic steps of the design process and describe what each one produces.
 
**Q2.** [5]
 
Explain why modularity and decomposition are needed in large software. Using the idea of low coupling and high cohesion, explain what makes a good split between components. Then distinguish between abstraction, encapsulation and information hiding.
 
**Q3.** [5]
 
Define any five of the following design metrics in one or two sentences.
 
(a) CBO

(b) LCOM

(c) WMC (with McCabe complexity)

(d) RFC

(e) DIT

(f) NOC
 
**Q4.** [5]
 
A `Rectangle` class has four attributes (`x`, `y`, `width`, `height`) and three methods. The number of methods using each attribute is:
 
m = 3, a = 4, m_x = 2, m_y = 2, m_width = 3, m_height = 3 (Σ m_ai = 10)
 
Calculate **LCOM2** and **LCOM3** for this class. Then explain what the two values tell you about the cohesion of the class.
 
**Q5.** [5]
 
Define each of the following architectural styles and give one example where it would be used.
 
(a) Layered architecture

(b) Event-based architecture

(c) Model-View-Controller (MVC)

(d) Blackboard / Repository

(e) Pipes and Filters
 
**Q6.** [5]
 
Explain the roles of the Model, the View and the Controller in MVC. Why can the user interface be described as a combination of the View and the Controller? Then explain how the UI design principles of *consistency* and *recoverability* should show up in such an interface.
 
**Q7.** [5]
 
Classify any five of the following Gang of Four (GoF) patterns as Creational, Structural or Behavioral, and state their intent in one line.
 
Factory Method, Singleton, Adapter, Decorator, Strategy, Observer
 
**Q8.** [5]
 
Explain how objects are mapped to database tables in an enterprise application. Describe when *Foreign Key Mapping* and when *Association Table Mapping* are used, with one example for each. Finally, give one advantage and one disadvantage of *Single Table Inheritance* and of *Class Table Inheritance*.
